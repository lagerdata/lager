# Linux impact ledger for the macOS port.
#
# Rule (docs/macos-port-plan.md, section 0.1): the working Linux Box must not
# regress. Every file that already exists on main under box/ or cli/ and is
# changed, renamed, or deleted by this work must be listed here BEFORE the
# change is committed. tools/check_linux_impact.py enforces it.
#
# New files need no entry: a Linux Box does not run them unless an existing
# file is changed to call them, and that change is what gets listed.
#
# One entry per line, four fields separated by " | ":
#
#   path | effect on a Linux Box | risk (low/medium/high) | how it was verified
#
# "path" is repo-relative and matched exactly. The last field must say plainly
# whether the change was run on real Linux hardware. Automated hardware runs
# are disabled, so "unit suites only; not run on Linux hardware" is the honest
# default until someone runs it on a bench.
#
box/lager/hardware_service.py | Instruments with a TCPIP address only: a dropped connection (reset, aborted, broken pipe) now takes the existing evict-reopen-retry path instead of failing until the service restarts. USB, serial and addressless devices do not take the new path; the stale-session keywords are unchanged | low | unit suites and a simulated network supply; not run on Linux hardware
box/start_box.sh | Stops detecting a pigpio container's address and no longer passes PIGPIO_ADDR to the Box container; the startup summary loses its "PIGPIO Address" line. Nothing else in the boot sequence changes | medium | unit suites and bash -n; not run on Linux hardware. This is the script every Linux Box boots with, so start one real Box before release
box/lager/python/executor.py | User scripts no longer get a PIGPIO_ADDR environment variable from the Box. A value the caller passes itself (--passenv / --env) still reaches the script. The project owner confirmed no customer script reads it | low | unit suites; not run on Linux hardware
box/lager/exec/docker.py | Removes the unused PIGPIO_CONTAINER_NAME constant | low | unit suites; nothing imports it
box/lager/exec/README.md | Documentation only: drops the removed constant | low | not applicable
box/lager/python/README.md | Documentation only: drops PIGPIO_ADDR from the script environment list | low | not applicable
box/oscilloscope-daemon/daemon/src/oscilloscope/pico/loader.rs | None at run time: adds a macOS-only driver search (two constants and one block, all under cfg(target_os = "macos")) that is compiled out of a Linux build. The Linux search directories and candidate names are untouched | low | loader tests pass on macOS; not built on Linux, so build the daemon on one Box before release
box/lager/nets/debug_net.py | None unless the container is started with LAGER_HOSTLINK=1, which only the macOS start script sets: then make_debug returns a stand-in that calls the host agent. Unset (every Linux Box), the added block reads one environment variable at import and does nothing else | low | box unit suite; not run on Linux hardware
