# Linux impact ledger for the macOS port.
#
# Rule (docs/macos-port-plan.md, section 0.1): the working Linux Box must not
# regress. Every file that already exists on main under box/ or cli/ and is
# changed, renamed, or deleted by this work must be listed here BEFORE the
# change is committed. tools/check_linux_impact.py enforces it.
#
# New files need no entry: a Linux Box does not run them unless an existing
# file is changed to call them, and that change is what gets listed.
#
# One entry per line, four fields separated by " | ":
#
#   path | effect on a Linux Box | risk (low/medium/high) | how it was verified
#
# "path" is repo-relative and matched exactly. The last field must say plainly
# whether the change was run on real Linux hardware. Automated hardware runs
# are disabled, so "unit suites only; not run on Linux hardware" is the honest
# default until someone runs it on a bench.
#
box/lager/hardware_service.py | Instruments with a TCPIP address only: a dropped connection (reset, aborted, broken pipe) now takes the existing evict-reopen-retry path instead of failing until the service restarts. USB, serial and addressless devices do not take the new path; the stale-session keywords are unchanged | low | unit suites and a simulated network supply; not run on Linux hardware
box/start_box.sh | Stops detecting a pigpio container's address and no longer passes PIGPIO_ADDR to the Box container; the startup summary loses its "PIGPIO Address" line. Nothing else in the boot sequence changes | medium | unit suites and bash -n; not run on Linux hardware. This is the script every Linux Box boots with, so start one real Box before release
box/lager/python/executor.py | User scripts no longer get a PIGPIO_ADDR environment variable from the Box. A value the caller passes itself (--passenv / --env) still reaches the script. The project owner confirmed no customer script reads it | low | unit suites; not run on Linux hardware

box/lager/exec/README.md | Documentation only: drops the removed constant | low | not applicable

cli/commands/utility/install.py | `lager install` with neither --box nor --ip used to print "Either --box or --ip is required" and exit 1. It now installs onto the machine it runs on: on macOS it provisions a local Box, on Linux and Windows it exits 1 with a "not yet supported" message. With --box or --ip the code path is unchanged, except that a CLI running on macOS sends a loopback address to the same local install; that check is always false on Linux and Windows. With --box or --ip and a target that is not this Mac, one command is added after the SSH check succeeds: `ssh -o BatchMode=yes <box> uname -s` (20 s limit). Only the exact answer "Darwin" leaves the Linux path, for the macOS installer; any other answer, an error, a timeout or no answer continues to the unchanged gateway check and deploy. A Linux install therefore makes one more SSH connection than before | medium | CLI unit suite; not run against a Linux Box, so run `lager install --ip` against one before release
cli/commands/box/boxes.py | `lager boxes edit` reads the saved record once more and passes its python_port, if any, to add_box. No Box records one today except a Box on macOS, so the saved file is byte-identical for a Linux Box. It passes the record's platform, if any, the same way; no Linux Box records one | low | CLI unit suite; not run against a Linux Box
cli/commands/utility/uninstall.py | `lager uninstall` with neither --box nor --ip used to print "Either --box or --ip is required" and exit 1. It now uninstalls from the machine it runs on: on macOS it removes the local Box, on Linux and Windows it exits 1 with a "not yet supported" message. With --box or --ip the code path is unchanged, except that a CLI running on macOS sends a loopback address to the same local uninstall; that check is always false on Linux and Windows. After address validation one more check reads the saved-Boxes file: a Box whose record has "platform": "macos" goes to the macOS uninstall. No Linux Box has that key, no network call is added, and an unreadable file counts as not a Mac | low | CLI unit suite; not run against a Linux Box
