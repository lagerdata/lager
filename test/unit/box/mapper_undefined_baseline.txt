# Mapper methods that no driver defines -- the known-undefined baseline.
#
# box/lager/nets/mappers/rigol_mso5000.py calls these on `self`. The mapper's
# __getattr__ forwards an unknown name to the Device proxy, which forwards it
# to the box, where hardware_service does a bare hasattr on the driver and
# returns 404 "Function not found". So every name here is a command that fails
# at runtime and cannot fail any earlier.
#
# This file exists so the guard in test_rigol_mso5000_la.py can be widened to
# the whole mapper without turning `unit (box)` red. It is TWO-SIDED:
#
#   * a NEW undefined name fails the test -- that is the point
#   * a name here that becomes defined ALSO fails, so the list ratchets down
#     and cannot rot into a list of things that were fixed years ago
#
# Shrink it by implementing methods, never by adding to it. Adding a line is
# only correct when a mapper legitimately gains a call the driver will grow
# later, and that should be rare enough to argue for in review.
#
# One line per entry, `ClassName.method_name`, sorted.
