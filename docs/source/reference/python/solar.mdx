---
title: Solar Simulation
description: Control solar panel simulation nets
---

Simulate solar panel characteristics for testing solar-powered devices. A solar net drives an
EA PSB bidirectional supply in its photovoltaic simulation mode.

<Warning>
A solar net has no `Net.get()` path. The CLI saves a solar net with the role `solar`, and
`NetType` has no `solar` role, so `Net.get('SOLAR', type=NetType.PowerSupply2Q)` raises
`InvalidNetError`. Use the module functions on this page instead. They take the net name. See [#844](https://github.com/lagerdata/lager/issues/844).
</Warning>

## Import

```python
from lager.power.solar import (
    set_to_solar_mode,
    stop_solar_mode,
    irradiance,
    mpp_current,
    mpp_voltage,
    resistance,
    temperature,
    voc,
)
```

The same functions are in `lager.power`, where `resistance`, `temperature` and `voc` are
named `solar_resistance`, `solar_temperature` and `solar_voc`.

## Functions

| Function | Description |
|----------|-------------|
| `set_to_solar_mode(netname)` | Connect and start photovoltaic simulation mode |
| `stop_solar_mode(netname)` | Stop the simulation and disconnect |
| `irradiance(netname, value=None)` | Set the irradiance (W/m²), or print it |
| `mpp_current(netname)` | Print the maximum power point current |
| `mpp_voltage(netname)` | Print the maximum power point voltage |
| `voc(netname)` | Print the open-circuit voltage |
| `temperature(netname)` | Print the simulated cell temperature |
| `resistance(netname, value=None)` | Set the panel resistance, or print it |

<Note>
Each function prints its result to the script's output and returns `None`. A script cannot
read a value from the return value. Each function raises `SolarBackendError` when the
instrument refuses a value or does not answer.
</Note>

## Function Reference

### `set_to_solar_mode(netname)`

Connect to the instrument and start photovoltaic simulation mode. The function tries three
times, because an EA supply needs time to settle after a stop.

```python
from lager.power.solar import set_to_solar_mode

set_to_solar_mode('SOLAR')
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `netname` | `str` | Name of the solar net |

### `stop_solar_mode(netname)`

Stop the simulation and disconnect from the instrument.

```python
from lager.power.solar import stop_solar_mode

stop_solar_mode('SOLAR')
```

### `irradiance(netname, value=None)`

Set the irradiance level, or print it when `value` is `None`.

```python
from lager.power.solar import irradiance

irradiance('SOLAR', 1000)  # Standard test condition (1000 W/m²)
irradiance('SOLAR')        # Prints the irradiance
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `netname` | `str` | Name of the solar net |
| `value` | `float` or `None` | Irradiance in W/m² (0-1500). If None, prints the value. |

A value below 0 or above 1500 raises `SolarBackendError`.

### `voc(netname)`

Print the open-circuit voltage.

```python
from lager.power.solar import voc

voc('SOLAR')
```

### `mpp_voltage(netname)`

Print the maximum power point voltage.

```python
from lager.power.solar import mpp_voltage

mpp_voltage('SOLAR')
```

### `mpp_current(netname)`

Print the maximum power point current.

```python
from lager.power.solar import mpp_current

mpp_current('SOLAR')
```

### `resistance(netname, value=None)`

Set the dynamic panel resistance, or print it when `value` is `None`.

```python
from lager.power.solar import resistance

resistance('SOLAR', 5.0)  # Set
resistance('SOLAR')       # Prints the resistance
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `netname` | `str` | Name of the solar net |
| `value` | `float` or `None` | Resistance in ohms. Must be positive. If None, prints the value. |

### `temperature(netname)`

Print the simulated cell temperature.

```python
from lager.power.solar import temperature

temperature('SOLAR')
```

## Examples

### Basic Solar Simulation

```python
from lager.power.solar import (
    set_to_solar_mode, stop_solar_mode, irradiance, voc, mpp_voltage, mpp_current,
)
import time

set_to_solar_mode('SOLAR_INPUT')
try:
    irradiance('SOLAR_INPUT', 1000)
    time.sleep(1)

    # Each call prints its reading
    voc('SOLAR_INPUT')
    mpp_voltage('SOLAR_INPUT')
    mpp_current('SOLAR_INPUT')
finally:
    stop_solar_mode('SOLAR_INPUT')
```

### Test Multiple Irradiance Levels

```python
from lager.power.solar import set_to_solar_mode, stop_solar_mode, irradiance, voc, mpp_current
import time

set_to_solar_mode('SOLAR')
try:
    for irr in [200, 500, 800, 1000, 1200]:
        irradiance('SOLAR', irr)
        time.sleep(1)
        print(f"Irradiance: {irr} W/m²")
        voc('SOLAR')
        mpp_current('SOLAR')
finally:
    stop_solar_mode('SOLAR')
```

### Measure the DUT Against a Fixed Irradiance

```python
from lager import Net, NetType
from lager.power.solar import set_to_solar_mode, stop_solar_mode, irradiance
import time

dut_current = Net.get('DUT_CURRENT', type=NetType.ADC)

set_to_solar_mode('SOLAR')
try:
    irradiance('SOLAR', 1000)
    for i in range(30):
        print(f"DUT input: {dut_current.input():.3f} V")
        time.sleep(1)
finally:
    stop_solar_mode('SOLAR')
```

## Supported Hardware

| Manufacturer | Model | Features |
|--------------|-------|----------|
| EA | PSB 10060-60 | Bidirectional, PV simulation |
| EA | PSB 10080-60 | Bidirectional, PV simulation |

Only EA PSB models are accepted. Another instrument on a solar net raises
`SolarBackendError`.

## Notes

- Solar simulation requires a bidirectional (two-quadrant) power supply
- Standard Test Conditions (STC): 1000 W/m², 25°C, AM1.5
- The I-V curve is automatically generated based on irradiance
- Call `set_to_solar_mode()` before the other functions
- Always call `stop_solar_mode()` when finished, for example in a `finally` block
- **The functions print and return `None`**. The printed text includes terminal color codes
- The CLI equivalent is [`lager solar`](/source/reference/cli/solar)
