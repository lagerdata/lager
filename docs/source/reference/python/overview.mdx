The Lager Python SDK provides a powerful, object-oriented interface for controlling hardware and automating tests on your Device Under Test (DUT). It enables programmatic control of power supplies, sensors, debug probes, and more.

## Import

```python
from lager import Net, NetType  # Convenience import for Net and NetType
```

## Core Classes

| Class | Description | Import |
|-------|-------------|--------|
| [`binaries`](./binaries) | Execute custom binaries | `from lager.binaries import run_custom_binary` |
| [`Net`](./net) | Core class for managing hardware connections | `from lager import Net, NetType` |
| [`Central`](./ble) | BLE scanning and connection | `from lager.ble import Central, Client` |

## Net Types

The SDK supports various net types for different hardware:

| NetType | Description | Hardware |
|---------|-------------|----------|
| `NetType.PowerSupply` | Programmable power supply | Rigol DP700/DP800, Keysight E36200/E36300, Keithley 2281S, Siglent SPD1000X, EA PSB |
| `NetType.PowerSupply2Q` | Two-quadrant supply. Not used by solar nets; see [Solar](./solar) | -- |
| `NetType.Battery` | Battery simulator | Keithley 2281S |
| `NetType.ELoad` | Electronic load | Rigol DL3000 |
| `NetType.Analog` | Oscilloscope (`scope` and `scope-channel` nets) | Rigol MSO5000, Rigol DS1000Z, PicoScope |
| `NetType.Logic` | Logic analyzer input | Rigol MSO5000 |
| `NetType.Waveform` | Not implemented | -- |
| `NetType.GPIO` | Digital I/O | LabJack T7/U3/U6, MCC USB-202, FT232H/FT2232H/FT4232H, Aardvark, YKUSH3 |
| `NetType.ADC` | Analog-to-digital converter | LabJack T7/U3/U6, MCC USB-202 |
| `NetType.DAC` | Digital-to-analog converter | LabJack T7/U3/U6, MCC USB-202 |
| `NetType.Thermocouple` | Temperature sensor | Phidget |
| `NetType.DMM` | Bench multimeter | Siglent SDM3065X |
| `NetType.Rotation` | Rotary encoder (legacy, see below) | Phidget encoder |
| `NetType.WattMeter` | Power meter | Yocto-Watt, Joulescope JS220, Nordic PPK2 |
| `NetType.UART` | Serial communication | USB Serial |
| `NetType.Debug` | Debug probe | J-Link, OpenOCD-supported probes |
| `NetType.Arm` | Robotic arm | Rotrics Dexarm |
| `NetType.Usb` | USB port control | Acroname, YKUSH, YKUSH3, Plugable |
| `NetType.Wifi` | WiFi module | Lager Box WiFi |
| `NetType.Actuate` | Move an arm to a saved position (legacy, see below) | Rotrics Dexarm |
| `NetType.SPI` | SPI bus communication | Aardvark, FT232H/FT2232H/FT4232H, LabJack T7, LabJack U3 |
| `NetType.I2C` | I2C bus communication | Aardvark, FT232H/FT2232H/FT4232H, LabJack T7, LabJack U3 |
| `NetType.EnergyAnalyzer` | Energy integration measurement | Joulescope JS220, Nordic PPK2 |
| `NetType.Webcam` | Video streaming | UVC cameras |
| `NetType.Hsm` | Hardware security module | YubiHSM 2 |
| `NetType.Router` | Network router control | MikroTik RouterOS |

## Quick Start

### List Available Nets

```python
from lager import Net

nets = Net.list_saved()
for net in nets:
    print(f"{net['name']}: {net['role']}")
```

### Control a Power Supply

```python
from lager import Net, NetType

# Get the power supply net
psu = Net.get('VDD', type=NetType.PowerSupply)

# Configure and enable
psu.set_voltage(3.3)
psu.set_current(0.5)
psu.enable()

# Read measurements
print(f"Voltage: {psu.voltage()}V")
print(f"Current: {psu.current()}A")

# Disable when done
psu.disable()
```

### Read an ADC

```python
from lager import Net, NetType

adc = Net.get('SENSOR', type=NetType.ADC)
voltage = adc.input()
print(f"Voltage: {voltage}V")
```

### Control GPIO

```python
from lager import Net, NetType

# Read input
button = Net.get('BUTTON', type=NetType.GPIO)
state = button.input()

# Set output
led = Net.get('LED', type=NetType.GPIO)
led.output(1)  # HIGH
led.output(0)  # LOW
```

### Control Debug Probe

```python
from lager import Net, NetType

# Get the debug net
debug = Net.get('jlink1', type=NetType.Debug)

# Connect and flash firmware
debug.connect()
debug.flash('firmware.hex')
debug.reset()
```

### Control USB Hub

```python
from lager import Net, NetType

# Get the USB net
usb = Net.get('SENSOR_USB', type=NetType.Usb)

# Power control
usb.enable()      # Power on
usb.disable()     # Power off
usb.toggle()      # Toggle state
```

## Complete Example

```python
from lager import Net, NetType
import time

# 1. Flash firmware
debug = Net.get('jlink1', type=NetType.Debug)
debug.connect()
debug.flash('firmware.hex')
debug.reset()
print("Firmware flashed")

# 2. Power on USB peripheral
usb = Net.get('SENSOR_USB', type=NetType.Usb)
usb.enable()
print("USB sensor powered on")

# 3. Enable main power
main_power = Net.get("VDD_MAIN", type=NetType.PowerSupply)
main_power.set_voltage(3.3)
main_power.enable()
print("Main power enabled")

# 4. Read sensor
sensor = Net.get("TEMP_SENSE", type=NetType.ADC)
temperature = sensor.input()
print(f"Temperature: {temperature}V")

# 5. Clean up
main_power.disable()
usb.disable()
print("Test complete")
```

## Run Records

Two functions connect a script to its run record. Both are top-level exports.

```python
import os
from lager import record_value, output_dir

record_value('dut.firmware', '1.4.2')   # A fact only the script knows
with open(os.path.join(output_dir(), 'results.csv'), 'w') as f:
    f.write('step,result\n')
```

| Function | Description |
|----------|-------------|
| `record_value(key, value)` | Write `key = value` into the run record's `scriptAsserted` section. Returns `True` when written, and `False` outside a recorded run |
| `output_dir()` | Return the run's output folder, and create it if necessary. Outside `lager python`, it is `lager-output` in the current directory |

A key is 1-128 letters, digits and `. _ : / -`, and starts with a letter or digit. A value is
a string of up to 4096 characters, a number, a boolean or `None`. A run records at most 256
keys, and the last value for a key wins. A value that the record cannot hold raises
`ValueError`. `lager python --download` brings back the files in `output_dir()` and the run
record. See [`lager python`](/source/reference/cli/python).

## Legacy Net Types

`NetType.Rotation` and `NetType.Actuate` have no `lager nets add` role. They work only for a
net that a saved record or `LAGER_MUXES` defines by hand.

| Class | Method | Description |
|-------|--------|-------------|
| `Rotation` | `read()` | Read a Phidget encoder. Returns `{'position': value}`. The location is `phidget:<serial>:<port>` |
| `Actuate` | `actuate()` | Move a Dexarm to the saved position. The location is a dict with `serial_number` and `position` (x, y, z) |

## Error Handling

```python
from lager import Net, NetType, InvalidNetError

try:
    net = Net.get('INVALID_NET', NetType.Analog)
except InvalidNetError as e:
    print(f"Net not found: {e}")
except Exception as e:
    print(f"Error: {e}")
```

## Notes

- Always call `disable()` when finished with power-related nets
- Simple nets (GPIO, ADC, DAC) don't require `enable()`/`disable()` calls
- Complex nets (PowerSupply, Battery, Analog) require `enable()` before use
- Net names must match those configured in the Lager system
- Use try/except blocks for robust error handling
