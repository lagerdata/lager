Discover and list all test instruments connected to a Lager Box.

## Syntax

```bash
lager instruments [OPTIONS]
```

## Options

| Option | Description |
|--------|-------------|
| `--box BOX` | Lager Box name or IP address |

---

## Usage

```bash
# List instruments on default Lager Box
lager instruments

# List instruments on specific Lager Box
lager instruments --box my-lager-box
```

---

## Output

The command displays a table of connected instruments. The `Channels` column has one line for each net type that the instrument offers, with the channels for that type. Use the name, a channel, and the address from this table with `lager nets add`.

```
Name                     Channels                                                       VISA Address
========================================================================================================================
Rigol_DP831              power-supply: 1, 2, 3                                          USB0::0x1AB1::0x0E31::DP8C123456789::INSTR
LabJack_U3               adc: AIN0, AIN1, AIN2, AIN3, AIN4, AIN5, AIN6, AIN7, AIN8,     USB0::0x0CD5::0x0003::::INSTR
                         AIN9, AIN10, AIN11, AIN12, AIN13, AIN14, AIN15
                         dac: DAC0, DAC1
                         gpio: FIO4, FIO5, FIO6, FIO7, EIO0, EIO1, EIO2, EIO3, EIO4,
                         EIO5, EIO6, EIO7, CIO0, CIO1, CIO2, CIO3
                         i2c: FIO6-FIO7
                         spi: FIO4-FIO7
```

The box holds the channel list. Run `lager update` on the box to get the current list.

## Instrument Types

The following instrument types are automatically detected:

### Power Supplies
- Rigol DP800 series (DP811, DP821, DP832)
- Keysight E36200/E36300 series
- Keithley 2200/2280 series
- EA PSB series

### Oscilloscopes
- Rigol MSO5000 series
- PicoScope

### Battery/Solar Simulators
- Keithley 2281S
- EA PSI/EL series

### Electronic Loads
- Rigol DL3000 series

### Data Acquisition
- LabJack T7 (ADC, DAC, GPIO, SPI, I2C)
- LabJack U3 (ADC, DAC, GPIO, SPI, I2C)
- MCC USB-202 (ADC, DAC, GPIO)
- Phidget thermocouples
- Yocto watt meters

### USB Hubs
- Acroname (4-port, 8-port)
- YKUSH

### Debug Probes
- Segger J-Link
- CMSIS-DAP
- ST-Link

### Serial Adapters
- FTDI USB-to-serial

## Two Devices That Report One Address

An address normally includes the USB serial number of the device, so two devices of one model have different addresses. Both appear in the table, and each can have nets.

A LabJack T7 and a LabJack U3 report no serial number. Two T7 units, or two U3 units, on one Lager Box therefore report the same address. A net cannot say which device it means. The command hides those rows and prints this message under the table:

```
LabJack_T7 at USB0::0x0CD5::0x0007::::INSTR: more than one device reports this address, so a net could not say which one it means. This model exposes no unique serial number. Use only one at a time, or drive them from separate boxes.
```

`lager nets add` refuses a net on that address. See [Nets](/source/reference/cli/nets) for the same rule in `add-all` and the TUI.

## Address Formats

Different instruments use different address formats:

| Type | Format | Example |
|------|--------|---------|
| USB instrument | `USB0::0x<VID>::0x<PID>::<serial>::INSTR` | `USB0::0x1AB1::0x0E31::DP8C123456789::INSTR` |
| LabJack T7 or U3 | USB resource with an empty serial field | `USB0::0x0CD5::0x0003::::INSTR` |
| Nordic PPK2 | `ppk2:<serial>` | `ppk2:ABCDEF123456` |
| Assigned RS-232 instrument | `serial://<vid>:<pid>/serial/<serial>` | `serial://067b:23a3/serial/00000006` |

## Examples

```bash
# Check what instruments are connected
lager instruments --box my-lager-box

# Use with nets command to configure
lager instruments --box my-lager-box
lager nets --box my-lager-box  # Then configure nets for discovered instruments
```

## Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| No instruments listed | USB cables disconnected, or Docker not running | Check physical USB connections. Run `lager hello --box <box>` to verify the service is running. |
| Specific instrument missing | Instrument needs power, USB re-seat, or updated udev rules | Unplug and replug the USB cable. Ensure the instrument is powered on. Run `lager update --box <box>` for latest drivers. |
| "more than one device reports this address" message | Two devices with no serial number, such as two LabJack T7 units, are connected | Use only one of them on this Lager Box. Connect the other one to a different Lager Box. |

## Notes

- Instruments must be connected via USB to the Lager Box
- Some instruments require specific drivers (udev rules)
- Run `lager update` to install latest udev rules
- Use `lager nets` to configure how instruments are used
