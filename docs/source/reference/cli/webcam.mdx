Control webcam streaming for visual monitoring of devices.

## Syntax

```bash
lager webcam [NETNAME] COMMAND [OPTIONS]
```

## Commands

| Command | Description |
|---------|-------------|
| `start` | Start webcam stream |
| `snapshot` | Save one JPEG frame from a running stream |
| `stop` | Stop webcam stream |
| `url` | Print URLs of all active streams |
| `start-all` | Start all webcam streams |
| `stop-all` | Stop all webcam streams |

## Options

| Option | Description |
|--------|-------------|
| `--box BOX` | Lager Box name or IP address |

---

## Command Reference

### `start`

Start a webcam stream.

```bash
lager webcam CAM1 start --box my-lager-box
```

### `snapshot`

Save one frame from a running stream as a JPEG. This is the right way for
scripts and assistants to look at the bench. The frame comes back over the
box's command endpoint, so the stream's own port never has to be reachable.

```bash
lager webcam CAM1 snapshot --box my-lager-box --out frame.jpg
```

Without `--out` the file is named `CAM1-<timestamp>.jpg` in the current
directory. The stream must already be running.

### `stop`

Stop a webcam stream.

```bash
lager webcam CAM1 stop --box my-lager-box
```

### `url`

Print URLs of all active webcam streams, with who started each one when
the box recorded it.

```bash
lager webcam url --box my-lager-box
```

Output:
```
Active webcam streams on <BOX_IP>:

CAM1:
  URL: http://<BOX_IP>:8086/
  Port: 8086
  Device: /dev/video0
  Origin: started via cli by alice
```

### Access-gated boxes

When a box sits behind an access gateway, its stream ports only admit
requests that carry your sign-in token. A browser cannot attach one from a
plain link. So `start`, `start-all` and `url` append the token to the
printed URL (`http://<BOX_IP>:8086/?token=...`), and say how many minutes
it stays valid. Run `lager webcam url` for a fresh link when it expires. If
no sign-in is stored for the box, the CLI tells you which `lager login`
URL to use.

### `start-all`

Start all configured webcam streams.

```bash
lager webcam start-all --box my-lager-box
```

### `stop-all`

Stop all webcam streams.

```bash
lager webcam stop-all --box my-lager-box
```

## Usage

### Basic Workflow

```bash
# Start a webcam
lager webcam CAM1 start --box my-lager-box

# Get the stream URL
lager webcam url --box my-lager-box

# Open in browser
# http://<BOX_IP>:8081/stream

# Stop when done
lager webcam CAM1 stop --box my-lager-box
```

### Multiple Cameras

```bash
# Start all cameras
lager webcam start-all --box my-lager-box

# View all URLs
lager webcam url --box my-lager-box

# Stop all cameras
lager webcam stop-all --box my-lager-box
```

## Stream Format

Webcam streams are provided as:
- **HTTP MJPEG streams** for browser viewing (`/stream`)
- **Single JPEG frames** on demand (`/snapshot`, or `lager webcam NET snapshot`)
- **Per-webcam ports** (8086, 8087, etc.)
- **Device path reporting** for debugging

Streams can be started and stopped from the CLI, the Python API, or other
tools that manage the same box. Each stream records which surface started
it, and any of them can stop it. One stream serves every viewer at once, but
a video device can only belong to one stream. Stop a stream before starting
another on the same camera.

## Use Cases

### Visual Inspection

Monitor physical state of device during testing:
```bash
lager webcam BENCH_CAM start
# Run tests while monitoring
lager webcam BENCH_CAM stop
```

### Remote Debugging

View LED states, display outputs, or physical connections:
```bash
lager webcam url --box my-lager-box
# Open stream in browser
```

### Documentation

Capture visual evidence of test results:
```bash
lager webcam BOARD_VIEW start
lager webcam BOARD_VIEW snapshot --out after-flash.jpg
lager webcam BOARD_VIEW stop
```

## Examples

```bash
# Set default webcam
lager defaults add --webcam-net MAIN_CAM

# Quick start/stop
lager webcam start
lager webcam stop

# Check status
lager webcam url
```

---

## Notes

- Webcams must be connected via USB to the box
- Each webcam uses a unique port (8086+)
- Streams are accessible via box IP address
- Default net can be set with `lager defaults add --webcam-net`
- USB webcams must be compatible with V4L2
