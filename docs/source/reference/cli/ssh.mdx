Open an interactive SSH session to a Lager Box, or run a single command on it
and return.

## Syntax

```bash
lager ssh [OPTIONS] [COMMAND]...
```

## Options

| Option | Description |
|--------|-------------|
| `--box BOX` | Lager Box name or IP address |

## Arguments

| Argument | Description |
|----------|-------------|
| `COMMAND` | Optional command to run on the box. If omitted, an interactive shell is opened. |

---

## Usage

```bash
# SSH to specific Lager Box (interactive shell)
lager ssh --box my-lager-box

# SSH to default Lager Box
lager ssh
```

### Run a command on the box

With a `COMMAND`, `lager ssh` behaves like `ssh user@host <command>`. It runs
the command on the box, streams its output back, and exits with the command's
exit code. There is no interactive shell. This is handy for scripting and
one-off checks.

```bash
# Run a single command and return
lager ssh --box lab-lager-box -- cat /etc/lager/version

# Flags pass through; use `--` to separate them from lager's own options
lager ssh --box lab-lager-box -- ls -la /etc/lager

# Inspect the running containers (the box login user is in the docker group)
lager ssh --box lab-lager-box -- docker ps
```

`lager ssh` with a `COMMAND` does not allocate a terminal. A remote `sudo`
command therefore works only when the box user has a passwordless grant for it.
Otherwise, run it in an interactive session.

<Note>Use `--` to separate lager's options from the remote command whenever the
command contains its own dashed flags, so they aren't parsed as `lager`
options. The remote command's exit code is propagated as `lager ssh`'s exit
code, so it composes cleanly in scripts.</Note>

## How It Works

The command:
1. Resolves the Lager Box name to IP address
2. Looks up the SSH username (default: `lagerdata`)
3. Chooses the SSH identities to offer
4. Opens an interactive SSH session, or runs the command

If `~/.ssh/lager_box` exists, `lager ssh` passes it with `-i`. The `-i` flag
replaces the default identity list of SSH instead of adding to it. So
`lager ssh` also names each of your own default keys that exists, after
`lager_box`. Those keys are `id_rsa`, `id_ecdsa`, `id_ecdsa_sk`, `id_ed25519`
and `id_ed25519_sk`. Identities from `~/.ssh/config` and agent keys stay on
offer. With no `lager_box` key, `lager ssh` passes no `-i` at all.

## Username Resolution

SSH usernames are resolved in order:
1. Username stored with box configuration (`lager boxes add --user`)
2. Default username: `lagerdata`

`lager ssh` looks up the stored username by box name. If you pass an IP address
to `--box`, it uses `lagerdata`. Pass the box name to use its stored username.

To use a different username for a Lager Box:
```bash
# Configure username when adding box
lager boxes add --name pi-lager-box --ip <BOX_IP> --user pi

# Or edit existing box
lager boxes edit --name pi-lager-box --user pi
```

## SSH Key Setup

For passwordless access, install the Lager SSH key on the box. The command asks
for the box password once:

```bash
lager ssh-setup --box my-lager-box
```

A key that you installed yourself with `ssh-copy-id` also works, because
`lager ssh` offers your default keys too. See
[SSH Setup](/source/reference/cli/ssh-setup).


## Common Tasks via SSH

Each of these can be run as a one-liner with `lager ssh --box <box> -- <command>`,
or interactively after `lager ssh --box <box>`.

### Check Container Status
```bash
lager ssh --box my-lager-box -- docker ps -a
lager ssh --box my-lager-box -- docker logs lager --tail 100
```

### View Lager Box Version
```bash
lager ssh --box my-lager-box -- cat /etc/lager/version
```

### Check Disk Space
```bash
lager ssh --box my-lager-box -- df -h
```

### View Firewall Status

`sudo` asks for a password on most boxes, so open an interactive session first:

```bash
lager ssh --box my-lager-box
sudo ufw status verbose
```

---

## Notes

- With no `COMMAND`, opens a fully interactive shell session (exit with `exit` or Ctrl+D)
- With a `COMMAND`, runs it on the box and exits with the command's exit code
- The session runs as a child process so Lager's cleanup hooks still fire
- Default Lager Box is used if `--box` not specified
