---
title: GPO
description: 设置 GPIO 输出电平
---

设置 GPIO 引脚的数字输出电平，并可选择保持模式，让输出一直有效直到被中断。

## 语法

```bash
lager gpo [NETNAME] LEVEL [OPTIONS]
```

## 参数

| 参数 | 说明 |
|----------|-------------|
| `NETNAME` | GPIO Net 名称（设置了默认值时可省略）。省略时会列出全部可用的 GPIO Net。 |
| `LEVEL` | 输出电平（见下文） |

## 电平取值

接受以下取值（不区分大小写）：

| 取值 | 结果 |
|-------|--------|
| `high`、`on`、`1` | 把引脚置为高电平 |
| `low`、`off`、`0` | 把引脚置为低电平 |
| `toggle` | 翻转当前状态 |

## 选项

| 选项 | 说明 |
|--------|-------------|
| `--box BOX` | Lager Box 名称或 IP 地址 |
| `--hold` | 为兼容旧脚本而保留，没有效果；请参阅[保持模式](#保持模式) |
| `--json` | 输出程序可读的 JSON 对象，而不是格式化文本 |

---

## 用法

```bash
# Set pin high
lager gpo LED1 high --box my-lager-box

# Set pin low
lager gpo LED1 low

# Toggle pin state
lager gpo LED1 toggle

# Using numeric values
lager gpo LED1 1
lager gpo LED1 0

# List available GPIO nets (omit net name and level)
lager gpo --box my-lager-box
```

### 保持模式

`--hold` 没有效果（[#840](https://github.com/lagerdata/lager/issues/840)）。Box 会保持设备会话打开，因此无论是否加 `--hold`，命令退出后引脚都会保持其电平。命令会打印一条说明并退出。若要释放引脚，请把它设为另一个电平。

```bash
# The level stays until the next command changes it
lager gpo RESET_N low --box my-lager-box
lager gpo RESET_N high --box my-lager-box
```

## 受支持的硬件

| 设备 | 引脚 | 电压 |
|--------|------|---------|
| LabJack T7 | FIO0-FIO7、EIO0-EIO7、CIO0-CIO3、MIO0-MIO2 | 3.3V 逻辑 |
| LabJack U3 | FIO4-FIO7、EIO0-EIO7、CIO0-CIO3 | |
| MCC USB-202 | DIO0-DIO7 | 3.3V/5V TTL |
| Aardvark | SCL、SDA、MISO、SCK、MOSI、SS | 3.3V |
| FT232H、FT2232H | 4-15（AD4-AD7、AC0-AC7） | 3.3V |
| FT4232H | 0-7 | 3.3V |
| YKUSH3 | 1-3 | |

引脚一列列出 `lager nets add` 接受的确切通道写法。在多通道 FTDI 器件上，由 Net 的 interface 选择通道 A、B、C 或 D。

### LabJack U3 引脚

- `FIO0`-`FIO3` 不作为 `gpio` 通道提供。在 U3-HV 上它们是固定的高压模拟输入。
- Lager 把每一台 U3 都当作 U3-HV 对待，因此 U3-LV 同样失去这四条数字线。
- 写操作会把引脚设为数字模式并设为输出。
- 在 0.46.1 之前保存在 `FIO0`-`FIO3` 上的 `gpio` Net 仍会被列出，但使用时会失败。请删除那个 Net。

### Aardvark 引脚映射

Aardvark I2C/SPI 适配器在它的 10 针排针上提供 6 个 GPIO 引脚。请用信号名作为通道：

| 引脚 | 名称 | 排针针脚 |
|-----|------|------------|
| 0 | SCL | 1 |
| 1 | SDA | 3 |
| 2 | MISO | 5 |
| 3 | SCK | 7 |
| 4 | MOSI | 8 |
| 5 | SS | 9 |

### FT232H 引脚映射

FT232H 和 FT2232H 提供 12 个 GPIO 通道。`AD0`-`AD3` 不作为 `gpio` 通道提供：

| 引脚 | 名称 | 说明 |
|------|-------|-------------|
| 4-7 | AD4-AD7 | 端口 A 数据引脚 |
| 8-15 | AC0-AC7 | 端口 A 控制引脚 |

## 示例

```bash
# Control an LED
lager gpo LED1 on --box my-lager-box
sleep 1
lager gpo LED1 off --box my-lager-box

# Toggle reset line
lager gpo RESET_N low
sleep 0.1
lager gpo RESET_N high

# Blink pattern
for i in {1..5}; do
    lager gpo LED1 toggle
    sleep 0.5
done

# Assert a boot strap, flash, then release it
lager gpo BOOT0 high --box my-lager-box
lager debug flash --hex fw.hex --box my-lager-box
lager gpo BOOT0 low --box my-lager-box
```

## 说明

- GPO 只用于设置输出引脚
- 读取输入引脚请用 `lager gpi`
- 默认 Net 可以用 `lager defaults add --gpio-net` 设置
- 引脚必须在 Net 配置中被设为输出
- toggle 会先读取当前状态再取反
- USB-202 的通道是 `DIO0`-`DIO7`
- `--hold` 没有效果；它会打印一条说明并退出
- 命令设置好输出电平后立即退出；引脚会保持该状态，直到下一条命令
