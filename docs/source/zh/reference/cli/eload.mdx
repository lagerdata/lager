title: 电子负载
description: 控制电子负载的设置和模式
---

通过 Lager CLI 控制电子负载 Net。电子负载用于模拟各种负载条件，
以测试电源、电池和其他供电装置。

## 语法

```bash
lager eload [OPTIONS] NET_NAME COMMAND [ARGS]...
```

## 全局选项

| 选项 | 说明 |
|--------|-------------|
| `--box BOX` | Lager Box 名称或 IP 地址 |
| `--help` | 显示帮助信息并退出 |

下面的每个子命令（`cc`、`cv`、`cr`、`cp`、`state`）也都接受 `--json`，
它输出程序可读的 JSON 对象，而不是格式化文本。

## 命令

| 命令 | 说明 |
|---------|-------------|
| `cc` | 设置或读取恒流模式（A） |
| `cv` | 设置或读取恒压模式（V） |
| `cr` | 设置或读取恒阻模式（Ω） |
| `cp` | 设置或读取恒功率模式（W） |
| `state` | 显示电子负载的状态 |

## 命令参考

### `cc`

设置或读取恒流（CC）模式，单位安培。

```bash
lager eload NET_NAME cc [VALUE] [--box BOX]
```

**参数：**
- `VALUE` - 电流值，单位安培（0–40 A）。省略时读取当前设置。超出范围的值会被拒绝。

在 CC 模式下，无论电压如何变化，电子负载都保持恒定的电流消耗。

**示例：**
```bash
# 把恒流设为 2.5A
lager eload LOAD1 cc 2.5

# 读取当前的 CC 设置
lager eload LOAD1 cc
```

### `cv`

设置或读取恒压（CV）模式，单位伏特。

```bash
lager eload NET_NAME cv [VALUE] [--box BOX]
```

**参数：**
- `VALUE` - 电压值，单位伏特（0–150 V）。省略时读取当前设置。超出范围的值会被拒绝。

在 CV 模式下，电子负载调节电流，以在它的端子上保持恒定电压。

### `cr`

设置或读取恒阻（CR）模式，单位欧姆。

```bash
lager eload NET_NAME cr [VALUE] [--box BOX]
```

**参数：**
- `VALUE` - 电阻值，单位欧姆（0.03–10000 Ω）。省略时读取当前设置。超出范围的值会被拒绝。

在 CR 模式下，电子负载表现为一个固定电阻，电流按欧姆定律（I = V/R）随电压变化。

### `cp`

设置或读取恒功率（CP）模式，单位瓦特。

```bash
lager eload NET_NAME cp [VALUE] [--box BOX]
```

**参数：**
- `VALUE` - 功率值，单位瓦特（0–200 W）。省略时读取当前设置。超出范围的值会被拒绝。

在 CP 模式下，电子负载调节电压和电流，以保持恒定的功率耗散。

### `state`

显示电子负载的当前状态。

```bash
lager eload NET_NAME state [--box BOX]
```

返回当前工作模式、设置值和测量值的信息。

---

## 示例

```bash
# 把恒流模式设为 1.5A
lager eload ELOAD1 cc 1.5 --box my-lager-box

# 把恒压模式设为 5V
lager eload ELOAD1 cv 5.0

# 把恒阻模式设为 10 欧姆
lager eload ELOAD1 cr 10.0

# 把恒功率模式设为 50W
lager eload ELOAD1 cp 50.0

# 查看当前状态
lager eload ELOAD1 state
```

## 工作模式

### 恒流（CC）

无论电压如何，负载都汲取固定电流：
- 用于测试电源的调节能力
- 非常适合电池放电测试
- 电压变化时电流保持稳定

### 恒压（CV）

负载在它的端子上保持固定电压：
- 模拟一个钳位电压的负载
- 适合测试带限流的电源
- 电流会变化以维持电压

### 恒阻（CR）

负载表现为一个固定电阻：
- 电流与电压成正比（欧姆定律）
- 模拟阻性负载
- 与许多真实负载的自然响应一致

### 恒功率（CP）

负载保持恒定的功率耗散：
- P = V × I 保持不变
- 电压下降时电流增大
- 模拟开关电源等类型的负载

## 说明

- Net 名称就是您搭建测试台时分配的名称
- 用 `lager nets` 查看可用的电子负载 Net
- 电子负载可能耗散很大的功率，请确保散热充分
- 施加大功率之前，请务必确认负载的额定参数
