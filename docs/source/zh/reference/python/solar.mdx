---
title: 太阳能仿真
description: 控制太阳能板仿真 Net
---

模拟太阳能板的特性，用于测试由太阳能供电的设备。太阳能 Net 驱动一台 EA PSB 双向电源，使其工作在光伏仿真模式。

<Warning>
太阳能 Net 没有 `Net.get()` 路径。CLI 以角色 `solar` 保存太阳能 Net，而 `NetType` 没有 `solar` 角色，因此 `Net.get('SOLAR', type=NetType.PowerSupply2Q)` 会引发 `InvalidNetError`。请改用本页的模块函数。它们接受 Net 名称作为参数。请参阅 [#844](https://github.com/lagerdata/lager/issues/844)。
</Warning>

## 导入

```python
from lager.power.solar import (
    set_to_solar_mode,
    stop_solar_mode,
    irradiance,
    mpp_current,
    mpp_voltage,
    resistance,
    temperature,
    voc,
)
```

`lager.power` 中也有这些函数，其中 `resistance`、`temperature` 和 `voc` 分别名为 `solar_resistance`、`solar_temperature` 和 `solar_voc`。

## 函数

| 函数 | 说明 |
|----------|-------------|
| `set_to_solar_mode(netname)` | 连接并启动光伏仿真模式 |
| `stop_solar_mode(netname)` | 停止仿真并断开连接 |
| `irradiance(netname, value=None)` | 设置辐照度（W/m²），或打印当前值 |
| `mpp_current(netname)` | 打印最大功率点电流 |
| `mpp_voltage(netname)` | 打印最大功率点电压 |
| `voc(netname)` | 打印开路电压 |
| `temperature(netname)` | 打印模拟的电池温度 |
| `resistance(netname, value=None)` | 设置电池板内阻，或打印当前值 |

<Note>
每个函数都把结果打印到脚本的输出，并返回 `None`。脚本无法从返回值读取数值。当仪器拒绝某个值或没有应答时，函数会引发 `SolarBackendError`。
</Note>

## 函数参考

### `set_to_solar_mode(netname)`

连接仪器并启动光伏仿真模式。由于 EA 电源在停止后需要时间稳定，该函数会尝试三次。

```python
from lager.power.solar import set_to_solar_mode

set_to_solar_mode('SOLAR')
```

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `netname` | `str` | 太阳能 Net 的名称 |

### `stop_solar_mode(netname)`

停止仿真并断开与仪器的连接。

```python
from lager.power.solar import stop_solar_mode

stop_solar_mode('SOLAR')
```

### `irradiance(netname, value=None)`

设置辐照度；当 `value` 为 `None` 时打印当前值。

```python
from lager.power.solar import irradiance

irradiance('SOLAR', 1000)  # Standard test condition (1000 W/m²)
irradiance('SOLAR')        # Prints the irradiance
```

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `netname` | `str` | 太阳能 Net 的名称 |
| `value` | `float` 或 `None` | 辐照度，单位 W/m²（0-1500）。为 None 时打印当前值。 |

小于 0 或大于 1500 的值会引发 `SolarBackendError`。

### `voc(netname)`

打印开路电压。

```python
from lager.power.solar import voc

voc('SOLAR')
```

### `mpp_voltage(netname)`

打印最大功率点电压。

```python
from lager.power.solar import mpp_voltage

mpp_voltage('SOLAR')
```

### `mpp_current(netname)`

打印最大功率点电流。

```python
from lager.power.solar import mpp_current

mpp_current('SOLAR')
```

### `resistance(netname, value=None)`

设置电池板的动态内阻；当 `value` 为 `None` 时打印当前值。

```python
from lager.power.solar import resistance

resistance('SOLAR', 5.0)  # Set
resistance('SOLAR')       # Prints the resistance
```

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `netname` | `str` | 太阳能 Net 的名称 |
| `value` | `float` 或 `None` | 内阻，单位为欧姆，必须为正数。为 None 时打印当前值。 |

### `temperature(netname)`

打印模拟的电池温度。

```python
from lager.power.solar import temperature

temperature('SOLAR')
```

## 示例

### 基本的太阳能仿真

```python
from lager.power.solar import (
    set_to_solar_mode, stop_solar_mode, irradiance, voc, mpp_voltage, mpp_current,
)
import time

set_to_solar_mode('SOLAR_INPUT')
try:
    irradiance('SOLAR_INPUT', 1000)
    time.sleep(1)

    # Each call prints its reading
    voc('SOLAR_INPUT')
    mpp_voltage('SOLAR_INPUT')
    mpp_current('SOLAR_INPUT')
finally:
    stop_solar_mode('SOLAR_INPUT')
```

### 测试多个辐照度等级

```python
from lager.power.solar import set_to_solar_mode, stop_solar_mode, irradiance, voc, mpp_current
import time

set_to_solar_mode('SOLAR')
try:
    for irr in [200, 500, 800, 1000, 1200]:
        irradiance('SOLAR', irr)
        time.sleep(1)
        print(f"Irradiance: {irr} W/m²")
        voc('SOLAR')
        mpp_current('SOLAR')
finally:
    stop_solar_mode('SOLAR')
```

### 在固定辐照度下测量 DUT

```python
from lager import Net, NetType
from lager.power.solar import set_to_solar_mode, stop_solar_mode, irradiance
import time

dut_current = Net.get('DUT_CURRENT', type=NetType.ADC)

set_to_solar_mode('SOLAR')
try:
    irradiance('SOLAR', 1000)
    for i in range(30):
        print(f"DUT input: {dut_current.input():.3f} V")
        time.sleep(1)
finally:
    stop_solar_mode('SOLAR')
```

## 受支持的硬件

| 制造商 | 型号 | 特性 |
|--------------|-------|----------|
| EA | PSB 10060-60 | 双向，光伏仿真 |
| EA | PSB 10080-60 | 双向，光伏仿真 |

只接受 EA PSB 型号。太阳能 Net 上的其他仪器会引发 `SolarBackendError`。

## 说明

- 太阳能仿真需要双向（双象限）电源
- 标准测试条件（STC）：1000 W/m²、25°C、AM1.5
- I-V 曲线会根据辐照度自动生成
- 请先调用 `set_to_solar_mode()`，再使用其他函数
- 结束时务必调用 `stop_solar_mode()`，例如放在 `finally` 块中
- **这些函数只打印并返回 `None`**。打印的文本包含终端颜色代码
- 对应的 CLI 命令是 [`lager solar`](/source/zh/reference/cli/solar)
