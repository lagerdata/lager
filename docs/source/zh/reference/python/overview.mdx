Lager Python SDK 提供了一套强大的面向对象接口，用于控制硬件并在您的被测设备（DUT）上实现测试自动化。它可以通过程序控制电源、传感器、调试探针等设备。

## 导入

```python
from lager import Net, NetType  # Convenience import for Net and NetType
```

## 核心类

| 类 | 说明 | 导入方式 |
|-------|-------------|--------|
| [`binaries`](/source/zh/reference/python/binaries) | 执行自定义二进制程序 | `from lager.binaries import run_custom_binary` |
| [`Net`](/source/zh/reference/python/net) | 管理硬件连接的核心类 | `from lager import Net, NetType` |
| [`Central`](/source/zh/reference/python/ble) | BLE 扫描与连接 | `from lager.ble import Central, Client` |

## Net 类型

该 SDK 为不同硬件支持多种 Net 类型：

| NetType | 说明 | 硬件 |
|---------|-------------|----------|
| `NetType.PowerSupply` | 可编程电源 | Rigol DP700/DP800、Keysight E36200/E36300、Keithley 2281S、Siglent SPD1000X、EA PSB |
| `NetType.PowerSupply2Q` | 双象限电源。太阳能 Net 不使用它；请参阅[太阳能](./solar) | -- |
| `NetType.Battery` | 电池模拟器 | Keithley 2281S |
| `NetType.ELoad` | 电子负载 | Rigol DL3000 |
| `NetType.Analog` | 示波器（`scope` 和 `scope-channel` Net） | Rigol MSO5000、Rigol DS1000Z、PicoScope |
| `NetType.Logic` | 逻辑分析仪输入 | Rigol MSO5000 |
| `NetType.Waveform` | 尚未实现 | -- |
| `NetType.GPIO` | 数字 I/O | LabJack T7/U3/U6、MCC USB-202、FT232H/FT2232H/FT4232H、Aardvark、YKUSH3 |
| `NetType.ADC` | 模数转换器 | LabJack T7/U3/U6、MCC USB-202 |
| `NetType.DAC` | 数模转换器 | LabJack T7/U3/U6、MCC USB-202 |
| `NetType.Thermocouple` | 温度传感器 | Phidget |
| `NetType.DMM` | 台式万用表 | Siglent SDM3065X |
| `NetType.Rotation` | 旋转编码器（旧版，见下文） | Phidget 编码器 |
| `NetType.WattMeter` | 功率计 | Yocto-Watt、Joulescope JS220、Nordic PPK2 |
| `NetType.UART` | 串行通信 | USB 串口 |
| `NetType.Debug` | 调试探针 | J-Link、OpenOCD 支持的探针 |
| `NetType.Arm` | 机械臂 | Rotrics Dexarm |
| `NetType.Usb` | USB 端口控制 | Acroname、YKUSH、YKUSH3、Plugable |
| `NetType.Wifi` | WiFi 模块 | Lager Box WiFi |
| `NetType.Actuate` | 把机械臂移动到保存的位置（旧版，见下文） | Rotrics Dexarm |
| `NetType.SPI` | SPI 总线通信 | Aardvark、FT232H/FT2232H/FT4232H、LabJack T7、LabJack U3 |
| `NetType.I2C` | I2C 总线通信 | Aardvark、FT232H/FT2232H/FT4232H、LabJack T7、LabJack U3 |
| `NetType.EnergyAnalyzer` | 能量积分测量 | Joulescope JS220、Nordic PPK2 |
| `NetType.Webcam` | 视频串流 | UVC 摄像头 |
| `NetType.Hsm` | 硬件安全模块 | YubiHSM 2 |
| `NetType.Router` | 网络路由器控制 | MikroTik RouterOS |

## 快速上手

### 列出可用的 Net

```python
from lager import Net

nets = Net.list_saved()
for net in nets:
    print(f"{net['name']}: {net['role']}")
```

### 控制电源

```python
from lager import Net, NetType

# Get the power supply net
psu = Net.get('VDD', type=NetType.PowerSupply)

# Configure and enable
psu.set_voltage(3.3)
psu.set_current(0.5)
psu.enable()

# Read measurements
print(f"Voltage: {psu.voltage()}V")
print(f"Current: {psu.current()}A")

# Disable when done
psu.disable()
```

### 读取 ADC

```python
from lager import Net, NetType

adc = Net.get('SENSOR', type=NetType.ADC)
voltage = adc.input()
print(f"Voltage: {voltage}V")
```

### 控制 GPIO

```python
from lager import Net, NetType

# Read input
button = Net.get('BUTTON', type=NetType.GPIO)
state = button.input()

# Set output
led = Net.get('LED', type=NetType.GPIO)
led.output(1)  # HIGH
led.output(0)  # LOW
```

### 控制调试探针

```python
from lager import Net, NetType

# Get the debug net
debug = Net.get('jlink1', type=NetType.Debug)

# Connect and flash firmware
debug.connect()
debug.flash('firmware.hex')
debug.reset()
```

### 控制 USB 集线器

```python
from lager import Net, NetType

# Get the USB net
usb = Net.get('SENSOR_USB', type=NetType.Usb)

# Power control
usb.enable()      # Power on
usb.disable()     # Power off
usb.toggle()      # Toggle state
```

## 完整示例

```python
from lager import Net, NetType
import time

# 1. Flash firmware
debug = Net.get('jlink1', type=NetType.Debug)
debug.connect()
debug.flash('firmware.hex')
debug.reset()
print("Firmware flashed")

# 2. Power on USB peripheral
usb = Net.get('SENSOR_USB', type=NetType.Usb)
usb.enable()
print("USB sensor powered on")

# 3. Enable main power
main_power = Net.get("VDD_MAIN", type=NetType.PowerSupply)
main_power.set_voltage(3.3)
main_power.enable()
print("Main power enabled")

# 4. Read sensor
sensor = Net.get("TEMP_SENSE", type=NetType.ADC)
temperature = sensor.input()
print(f"Temperature: {temperature}V")

# 5. Clean up
main_power.disable()
usb.disable()
print("Test complete")
```

## 运行记录

有两个函数把脚本与它的运行记录关联起来。两者都是顶层导出。

```python
import os
from lager import record_value, output_dir

record_value('dut.firmware', '1.4.2')   # A fact only the script knows
with open(os.path.join(output_dir(), 'results.csv'), 'w') as f:
    f.write('step,result\n')
```

| 函数 | 说明 |
|----------|-------------|
| `record_value(key, value)` | 把 `key = value` 写入运行记录的 `scriptAsserted` 部分。写入时返回 `True`，不在记录的运行中时返回 `False` |
| `output_dir()` | 返回本次运行的输出文件夹，必要时创建它。在 `lager python` 之外，它是当前目录下的 `lager-output` |

键由 1-128 个字母、数字和 `. _ : / -` 组成，并以字母或数字开头。值可以是不超过 4096 个字符的字符串、数字、布尔值或 `None`。一次运行最多记录 256 个键，同一个键以最后写入的值为准。记录无法容纳的值会引发 `ValueError`。`lager python --download` 会取回 `output_dir()` 中的文件和运行记录。请参阅 [`lager python`](/source/zh/reference/cli/python)。

## 旧版 Net 类型

`NetType.Rotation` 和 `NetType.Actuate` 没有对应的 `lager nets add` 角色。它们只适用于由手写的保存记录或 `LAGER_MUXES` 定义的 Net。

| 类 | 方法 | 说明 |
|-------|--------|-------------|
| `Rotation` | `read()` | 读取 Phidget 编码器。返回 `{'position': value}`。位置写作 `phidget:<serial>:<port>` |
| `Actuate` | `actuate()` | 把 Dexarm 移动到保存的位置。位置是一个包含 `serial_number` 和 `position`（x、y、z）的字典 |

## 错误处理

```python
from lager import Net, NetType, InvalidNetError

try:
    net = Net.get('INVALID_NET', NetType.Analog)
except InvalidNetError as e:
    print(f"Net not found: {e}")
except Exception as e:
    print(f"Error: {e}")
```

## 说明

- 用完与电源有关的 Net 之后，请务必调用 `disable()`
- 简单的 Net（GPIO、ADC、DAC）不需要调用 `enable()`/`disable()`
- 复杂的 Net（PowerSupply、Battery、Analog）在使用前需要先 `enable()`
- Net 名称必须与 Lager 系统中配置的名称一致
- 请用 try/except 块实现健壮的错误处理
