示波器模块提供用于波形采集、触发和测量的 Python 接口。

## 概述

用 scope 模块控制示波器，采集模拟信号、在特定事件上触发，并进行自动测量。

## 仪器支持

同一个对象和同样的调用既适用于 Rigol MSO5000，也适用于 PicoScope（2000、2000a、3000a、4000a 或 5000a）。区别在底层。Rigol 通过 VISA 使用 SCPI 通信。PicoScope 是带有厂商 SDK 的 USB 设备，由 Box 上的示波器守护进程驱动。

为 PicoScope 编写脚本之前，请先了解以下区别：

- **测量值是计算出来的，而不是查询得到的。** PicoTech 的任何 API 都没有与 `:MEAS:VPP?` 等价的命令，因此 Box 根据采集到的数据块计算该值。一次采集就能得出全部测量值，所以 `scope.measurement.all()` 的开销与单次 `voltage_peak_to_peak()` 相同，而逐个读取五个值需要五次采集。
- **运行时，它们描述最近一次串流发出的采集。** Box 根据它最近发送给订阅者的数据块计算测量值或光标读数，因此这些数值与屏幕上的波形一致。重复读取的变化速度不会超过采集到达的速度：在两次采集之间的两次调用返回相同的值。停止时，它们描述最后一次采集，就像停止状态下的台式示波器一样。
- **`display` 和 `measurement_cursor` 不起作用。** 它们把读数显示在仪器自己的屏幕上，而 PicoScope 没有屏幕。这两个参数会被接受并忽略，这样为 Rigol 编写的脚本仍然可以运行。
- **有些功能会抛出异常，而不是返回值。** 屏幕光标、协议触发、逻辑分析仪，以及下文列为仅限 Rigol 的测量，会抛出指明缺失功能的 `UnsupportedScopeFeature`，而不是返回一个看似合理的零值。如果脚本需要同时在两种仪器上运行，请捕获该异常。

PicoScope 的通道用字母表示（A-D），Rigol 的通道用数字表示（1-4）。每个方法都接受这两种写法并进行归一化，因此针对一种仪器编写的脚本在另一种仪器上也能继续工作。

## 导入

```python
from lager import Net, NetType
```

## 用法

```python
from lager import Net, NetType

# Get scope net
scope = Net.get('ANALOG1', type=NetType.Analog)

# Enable the channel
scope.enable()

# Start capture
scope.start_capture()

# Take measurements
freq = scope.measurement.frequency()
period = scope.measurement.period()

# Stop and disable
scope.stop_capture()
scope.disable()
```

## 方法

### 通道控制

#### `enable()`

启用该示波器通道。

```python
scope.enable()
```

#### `disable()`

停用该示波器通道。

```python
scope.disable()
```

### 采集控制

#### `start_capture()`

开始连续波形采集。

```python
scope.start_capture()
```

#### `start_single_capture()`

开始单次采集（采集一次触发事件）。

```python
scope.start_single_capture()
```

#### `stop_capture()`

停止波形采集。

```python
scope.stop_capture()
```

#### `force_trigger()`

立即触发，而不是等待配置的触发条件。当信号没有越过触发电平、而脚本仍然需要一次采集时，使用它。示波器必须处于运行状态：已停止的 PicoScope 会拒绝该调用。

```python
scope.force_trigger()
```

### 测量

通过 `measurement` 属性访问完整的测量功能。

#### 可用性

下面的所有测量都适用于 Rigol。在 PicoScope 上，Box 根据采集到的采样点计算测量值，它计算的是以下十四项：

| 两者均可用 | |
|---|---|
| `voltage_max` | `voltage_min` |
| `voltage_peak_to_peak` | `voltage_average` |
| `voltage_rms` | `voltage_overshoot` |
| `frequency` | `period` |
| `rise_time` | `fall_time` |
| `pulse_width_positive` | `pulse_width_negative` |
| `duty_cycle_positive` | `duty_cycle_negative` |

其他所有测量都**仅限 Rigol**，在 PicoScope 上会抛出 `UnsupportedScopeFeature`。它们包括平顶电压和阈值电压、预冲、周期 RMS、极值时刻、压摆率、边沿计数和脉冲计数、面积以及方差。延迟和相位测量同样仅限 Rigol，因为它们要比较两个通道。Box 在 PicoScope 上没有用于这种比较的命令。

`period`、`frequency`、脉冲宽度、占空比、上升和下降时间以及过冲都需要可分辨的波形。在 PicoScope 上，测量周期需要采集中包含两个完整周期。周期不足时，调用会抛出异常，而不是返回不精确的估计值。测量时序之前，请让屏幕上至少显示两个周期。

#### `all()`

Box 计算的每一项测量，全部来自同一次采集。在 PicoScope 上，这是读取多个值的低开销方式。

```python
values = scope.measurement.all()
print(values['vpp'], values['frequency'])
```

#### 电压测量

```python
# Basic voltage
vmax = scope.measurement.voltage_max()      # Maximum voltage
vmin = scope.measurement.voltage_min()      # Minimum voltage
vpp = scope.measurement.voltage_peak_to_peak()  # Peak-to-peak
vavg = scope.measurement.voltage_average()  # Average voltage
vrms = scope.measurement.voltage_rms()      # RMS voltage

# Waveform characteristics
vtop = scope.measurement.voltage_flat_top()    # Flat top voltage
vbase = scope.measurement.voltage_flat_base()  # Flat base voltage
vamp = scope.measurement.voltage_flat_amplitude()  # Amplitude

# Thresholds
vupper = scope.measurement.voltage_threshold_upper()
vlower = scope.measurement.voltage_threshold_lower()
vmid = scope.measurement.voltage_threshold_mid()

# Signal quality
overshoot = scope.measurement.voltage_overshoot()
preshoot = scope.measurement.voltage_preshoot()
```

#### 时序测量

```python
# Frequency and period
freq = scope.measurement.frequency()
period = scope.measurement.period()

# Rise and fall times
rise = scope.measurement.rise_time()
fall = scope.measurement.fall_time()

# Pulse widths
pos_width = scope.measurement.pulse_width_positive()
neg_width = scope.measurement.pulse_width_negative()

# Duty cycles
pos_duty = scope.measurement.duty_cycle_positive()
neg_duty = scope.measurement.duty_cycle_negative()

# Time at voltage extremes
t_vmax = scope.measurement.time_at_voltage_max()
t_vmin = scope.measurement.time_at_voltage_min()

# Slew rates
pos_slew = scope.measurement.positive_slew_rate()
neg_slew = scope.measurement.negative_slew_rate()
```

#### 计数测量

```python
# Edge counts
pos_edges = scope.measurement.positive_edge_count()
neg_edges = scope.measurement.negative_edge_count()

# Pulse counts
pos_pulses = scope.measurement.positive_pulse_count()
neg_pulses = scope.measurement.negative_pulse_count()
```

#### 面积测量

```python
area = scope.measurement.waveform_area()
period_area = scope.measurement.waveform_period_area()
```

#### 统计测量

```python
variance = scope.measurement.variance()
pvrms = scope.measurement.voltage_rms_period()  # Period RMS voltage
```

#### 延迟与相位测量

```python
# Delay measurements (between channels)
rr_delay = scope.measurement.delay_rising_rising_edge()
rf_delay = scope.measurement.delay_rising_falling_edge()
fr_delay = scope.measurement.delay_falling_rising_edge()
ff_delay = scope.measurement.delay_falling_falling_edge()

# Phase measurements
rr_phase = scope.measurement.phase_rising_rising_edge()
rf_phase = scope.measurement.phase_rising_falling_edge()
fr_phase = scope.measurement.phase_falling_rising_edge()
ff_phase = scope.measurement.phase_falling_falling_edge()
```

#### 测量选项

大多数测量都接受可选参数：

```python
# Keep measurement displayed on scope
freq = scope.measurement.frequency(display=True)

# Enable cursor measurement mode
vpp = scope.measurement.voltage_peak_to_peak(measurement_cursor=True)
```

## 串流（PicoScope）

PicoScope 设备支持串流功能：

### `stream_start(channel, volts_per_div, time_per_div, trigger_level, trigger_slope, capture_mode, coupling)`

启动串流采集。

**参数：**
- `channel`（str）：要启用的通道 —— `"A"`、`"B"`、`"1"`、`"2"`
- `volts_per_div`（float）：垂直刻度
- `time_per_div`（float）：水平刻度，单位秒
- `trigger_level`（float）：触发电平，单位伏特
- `trigger_slope`（str）：`"rising"`、`"falling"`、`"either"`
- `capture_mode`（str）：`"auto"`、`"normal"`、`"single"`
- `coupling`（str）：`"dc"`、`"ac"`

<Note>
API 接受 `"gnd"`，但 2000 系列设备会拒绝它，因为它们没有接地开关：`ps2000_set_channel` 只用一个标志表示耦合方式。要隔离直流分量，请使用 `"ac"`；要查看零电平的位置，请拔下探头。
</Note>

```python
scope.stream_start(
    channel="A",
    volts_per_div=1.0,
    time_per_div=0.001,
    trigger_level=0.5,
    trigger_slope="rising",
    capture_mode="auto",
    coupling="dc"
)
```

### `stream_stop()`

停止串流采集。

```python
scope.stream_stop()
```

### `stream_capture(output, duration, samples)`

采集 `duration` 秒，并写入 CSV 文件。

**参数：**
- `output`（str）：输出文件路径。省略它时只统计采样点数，不写文件
- `duration`（float）：采集时长，单位秒
- `samples`（int）：每个通道的行数上限（可选）。它是上限而不是目标：采集仍然在 `duration` 结束时停止

返回的是摘要而不是采样数据本身 —— `captures`、`samples_per_channel`、`rows` 和 `output`。CSV 的列为 `capture`、`channel`、`sample_index`、`time_ns` 和 `voltage`，与 `lager scope stream capture` 写出的格式相同。

这段时间内示波器完成的每一次采集都只记录一次。示波器必须已经在运行，由 `stream_start()`、`start_capture()` 或 `start_single_capture()` 启动。示波器处于停止状态时，调用会立即抛出异常，而不是等到 `duration` 结束后一无所获。相对的 `output` 路径以脚本在 Box 上的工作目录为基准。

```python
result = scope.stream_capture(
    output="waveform.csv",
    duration=5.0
)
print(result['samples_per_channel'], "samples per channel")
```

### `stream_frames(count, timeout)`

以解码后的帧逐个产出采集结果，而不是写入文件。这是零拷贝路径：帧的 `counts()` 是接收缓冲区上的视图，因此在需要之前不会进行任何转换。当采样数据要送入 numpy 而不是写入磁盘时，请使用它。

每一帧都是一次新的采集，绝不会重复产出之前产出过的采集。如果在 `timeout` 内没有采集到达，它会抛出 `ScopeDaemonTimeout`。请先启动示波器；在 normal 模式下，还要确保信号越过触发电平。

**参数：**
- `count`（int）：要产出的采集次数（默认 1）
- `timeout`（float）：等待每次采集的秒数（默认 10）

```python
for frame in scope.stream_frames(count=10):
    volts = frame.volts('A')          # numpy array, converted on request
    times = frame.time_axis()         # seconds relative to the trigger
    print(frame.sample_rate_hz, volts.max())
```

<Note>
`volts()` 给出探头尖端的电压。使用 10x 探头时，它报告的是尖端处的信号，而不是到达 BNC 接口的那十分之一。`volts_per_div`、触发电平和测量函数同样以探头尖端为准。请在采集之前用 `set_channel_probe()` 设置衰减比。2000 系列设备初始为 10x，2000a、3000a、4000a 和 5000a 系列初始为 1x。
</Note>

## 完整示例

```python
from lager import Net, NetType
import time

def measure_pwm_signal():
    """Measure PWM signal characteristics."""

    # Get scope net
    pwm_net = Net.get('PWM_OUTPUT', type=NetType.Analog)

    try:
        # Enable channel
        pwm_net.enable()

        # Configure trigger
        pwm_net.trigger_settings.set_mode_normal()
        pwm_net.trigger_settings.edge.set_source(pwm_net)
        pwm_net.trigger_settings.edge.set_slope_rising()
        pwm_net.trigger_settings.edge.set_level(1.65)  # 50% of 3.3V

        # Start capture
        pwm_net.start_capture()
        time.sleep(0.5)  # Wait for stable capture

        # Take measurements
        frequency = pwm_net.measurement.frequency()
        period = pwm_net.measurement.period()

        print(f"PWM Frequency: {frequency:.2f} Hz")
        print(f"PWM Period: {period*1000:.3f} ms")

        # Calculate duty cycle from pulse width if available
        # ...

    finally:
        pwm_net.stop_capture()
        pwm_net.disable()

if __name__ == "__main__":
    measure_pwm_signal()
```

### 波形显示设置

通过 `trace_settings` 配置垂直和水平刻度：

```python
# Vertical scale (V/div)
scope.trace_settings.set_volts_per_div(1.0)
volts = scope.trace_settings.get_volts_per_div()

# Vertical offset
scope.trace_settings.set_volt_offset(0.5)
offset = scope.trace_settings.get_volt_offset()

# Horizontal scale (s/div)
scope.trace_settings.set_time_per_div(0.001)  # 1ms/div
time_scale = scope.trace_settings.get_time_per_div()  # 0.001024 -- see below

# Horizontal offset
scope.trace_settings.set_time_offset(0.0)
time_offset = scope.trace_settings.get_time_offset()
```

<Note>
每格时间是一次采集的十分之一，与十格的屏幕相同，因此 `set_time_per_div(0.001)` 请求的是 10 ms 的窗口。

`get_time_per_div()` 返回实际使用的刻度，它很少恰好等于请求的值。示波器按一组固定的采样间隔采样，每一级是上一级的两倍。Box 把请求舍入到最接近的一级：2204A 上的 1 ms/div 实际是 1.024 ms/div。如果需要精确的窗口，请读回该值。更好的做法是使用 `get_sample_rate()` 和帧自身的时间轴，而不是根据设置的值进行计算。

设备能达到的最快屏幕取决于数据块深度和最大采样率，因为两者相乘就得到窗口。2204A 以 100 MS/s 采集 8000 个采样点时，最快为 8 us/div，请求更快的刻度也只会得到这个值。启用第二个通道会让缓冲区减半，这会让最快屏幕变得更快，而不是更慢。
</Note>

<Note>
`set_time_offset()` 相对于触发点在时间上移动采集窗口。用它查看单次采集左右边缘之外的信号。正值向前看，即触发之后的信号；负值向后看，即触发之前的信号。

在 PicoScope 上，每个方向最多移动一个窗口。窗口就是一个数据块，而一个数据块就是示波器能保存的全部内容。因此，Box 会把偏移限制在采集完全位于触发之前或完全位于触发之后的位置。设置偏移会重新启动示波器的触发等待，因为别处的窗口必须重新采集才能看到。此后，该偏移适用于每一次采集，直到您修改它。
</Note>

### 高级触发设置

通过 `trigger_settings` 访问高级触发配置：

```python
# Trigger mode
scope.trigger_settings.set_mode_auto()
scope.trigger_settings.set_mode_normal()
scope.trigger_settings.set_mode_single()
mode = scope.trigger_settings.get_mode()

# Trigger coupling (Rigol only -- a filter on the trigger path itself, which
# a PicoScope does not have. For a PicoScope, set the channel's input coupling
# with scope.set_channel_coupling('dc') instead.)
scope.trigger_settings.set_coupling_DC()
scope.trigger_settings.set_coupling_AC()
scope.trigger_settings.set_coupling_low_freq_reject()
scope.trigger_settings.set_coupling_high_freq_reject()
coupling = scope.trigger_settings.get_coupling()

# Edge trigger settings
scope.trigger_settings.edge.set_source(scope)
scope.trigger_settings.edge.set_slope_rising()
scope.trigger_settings.edge.set_slope_falling()
scope.trigger_settings.edge.set_slope_both()
scope.trigger_settings.edge.set_level(1.65)

# Get status
status = scope.trigger_settings.get_status()
```

### 光标控制

通过 `cursor` 属性访问光标功能。

<Note>
`scope.cursor.*` **仅限 Rigol**。它们是仪器自身屏幕上的标记，按屏幕坐标定位，并通过 SCPI 读回。PicoScope 没有屏幕，因此这里的每个方法在 PicoScope 上都会抛出 `UnsupportedScopeFeature`。

基于*采集到的采样点*的光标是另一回事，PicoScope 具备这种光标。您用时间和电压来放置它们，而不是用像素，因此它们有自己的 API。请使用 `lager scope <net> cursor time <t1> <t2>`、Web UI 控制台中同样的 `cursor` 命令，或者驱动上的 `set_cursors()` / `measure_cursors()`：

```python
scope.set_cursors(time=(0.0, 1e-3))
readings = scope.measure_cursors()["readings"]
readings["frequency"]       # 1/dt, so a pair a cycle apart reads the frequency
readings["trace_delta_v"]   # the trace's voltage change between them
```

这对光标保存在 Box 上。从脚本、终端 CLI 或 Web UI 控制台放置的光标是同样的两个标记，Web UI 会把它们画出来。
</Note>

```python
# Set cursor positions
scope.cursor.set_a(x=100, y=50)
scope.cursor.set_b(x=200, y=50)

# Get cursor positions
ax, ay = scope.cursor.get_a()
bx, by = scope.cursor.get_b()

# Move cursors relatively
scope.cursor.move_a(x_del=10, y_del=5)
scope.cursor.move_b(x_del=-10, y_del=0)

# Read cursor measurements
x_delta = scope.cursor.x_delta()  # Time difference
y_delta = scope.cursor.y_delta()  # Voltage difference
inv_x = scope.cursor.frequency()  # Frequency

# Get individual values
ax_val = scope.cursor.a_x()
ay_val = scope.cursor.a_y()
bx_val = scope.cursor.b_x()
by_val = scope.cursor.b_y()

# Hide cursor
scope.cursor.hide()
```

## 受支持的硬件

| 厂商 | 型号系列 | 特性 |
|--------------|--------------|----------|
| Rigol | MSO5000 | 多通道、混合信号、协议解码、光标、屏幕测量 |
| PicoScope | 2000、2000a、3000a、4000a、5000a | 采集控制、刻度设置、边沿触发、14 种计算测量、连续串流 |

Box 在运行时检测所连接 PicoScope 的通道数、电压量程、带宽、存储深度和 ADC 分辨率。因此，同一系列中的型号无需配置即可工作。用 `scope.capabilities()` 读取这些信息。

## 说明

- 示波器通道（1-4）请用 `NetType.Analog`
- MSO 示波器的数字通道（D0-D15）请用 `NetType.Logic`
- 串流功能仅在 PicoScope 设备上可用
- 为获得可靠的测量结果，请在开始采集之前先配置触发
- 测量方法成功时返回 `float`，测量无效时返回 `None`（例如无信号、无触发、通道不对）。在 Rigol 硬件上，仪器对无效测量返回 9.9E+37，它会被自动转换为 `None`
- 关于协议触发（UART、I2C、SPI、CAN），请参阅[逻辑分析仪](/source/zh/reference/python/logic)文档
